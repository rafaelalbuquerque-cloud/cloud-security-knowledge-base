# Knowledge base

The knowledge base is organized by platform and cross-cloud capability.

- `aws/`, `azure/`, and `oci/`: provider-specific architecture and security
- `kubernetes/`: cluster, workload, identity, and runtime security
- `terraform/`: secure infrastructure delivery and policy as code
- `devsecops/`: CI/CD, supply chain, and application security
- `finops/`: cost-aware controls and financial governance
- `ai-security/`: secure AI systems and future retrieval patterns
- `governance/`, `identity/`, `networking/`, and `incident-response/`:
  cross-cloud practices

Every major topic should follow the shared template and link to its related
labs, case studies, ADRs, and learning paths.
