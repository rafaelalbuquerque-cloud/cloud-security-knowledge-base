# Contributing

Contributions should make cloud security knowledge safer, clearer, or more
practical.

## Content workflow

1. Start from `templates/topic.md`.
2. Use professional English and define the intended maturity level.
3. Cite official vendor documentation for factual service behavior.
4. Add safe examples with fictional identifiers.
5. Explain alternatives and trade-offs, not only the preferred design.
6. Run the site build and review the rendered content.
7. Open a focused pull request with a validation summary.

## Definition of done

A complete topic should cover the concept, use cases, architecture, security,
cost, troubleshooting, implementation examples, labs, field lessons, and
references when those sections are relevant.
