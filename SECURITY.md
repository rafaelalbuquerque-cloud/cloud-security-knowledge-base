# Security and confidentiality

This repository contains reusable educational material, not production secrets.

Do not submit credentials, tokens, private keys, customer names, cloud account
IDs, tenant IDs, internal network ranges, production resource identifiers, or
confidential architecture details. Use obvious placeholders and anonymize all
enterprise scenarios.

If sensitive information is discovered, do not open a public issue containing
the data. Remove it from the proposed change and notify the repository owner
privately.
