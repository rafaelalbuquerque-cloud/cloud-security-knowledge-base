# Enterprise case studies

Case studies preserve reusable architectural lessons without exposing
confidential information.

## Required structure

- Context and anonymized problem
- Architecture and constraints
- Decisions and alternatives
- Trade-offs and operational impact
- Implementation approach
- Runbook and rollback
- Lessons learned

## Initial backlog

- Landing Zone Drift Recovery
- Centralized security tooling operating model
- Multi-cloud identity governance
- Security control rollout without workload disruption
